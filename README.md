# Dynatrace Application & Infrastructure Monitoring Lab

## Project Objective
This repository serves as a practical portfolio piece demonstrating hands-on proficiency in Dynatrace. It covers Application Performance Monitoring (APM), infrastructure monitoring, incident investigation, and log analysis using DQL.

## Tools & Skills
*   **Platform:** Dynatrace SaaS
*   **Core Skills:** DQL (Dynatrace Query Language), Infrastructure Monitoring, Incident Investigation, Dashboard Creation.

## Key Deliverables in this Repository
1.  **[Incident Investigation](incident-report.md):** A deep dive into Problem P-2610339, where I diagnosed a network bottleneck ("High rate of dropped packets") on a Red Hat VirtIO Ethernet Adapter.
2.  **[DQL Queries](dql-queries.md):** A collection of Dynatrace Query Language commands used for log filtering and aggregation.
3.  **Custom Monitoring Dashboard:** Built a comprehensive health dashboard featuring Top 10 Hosts by CPU, Host Memory allocation, Live Events, User Sessions, and custom DQL log tiles.
